# Справочник по боту

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | Регистрация пользователя, приветствие |
| `/list` | Список всех активных задач с кнопками управления |
| `/today` | Задачи, запланированные на сегодня |
| `/done` | Показать список задач для отметки выполненными |
| `/add` | Режим добавления задачи: бот просит написать задачу и время, затем показывает карточку подтверждения |
| `/sync` | Синхронизация с Google Tasks (двусторонняя) |
| `/watch <url>` | Начать следить за Google Doc, ежедневная проверка в 06:00 |
| `/sources` | Список отслеживаемых документов |
| `/family` | Список семейных задач с исполнителями |
| `/backup` | Запустить бэкап БД на Google Drive прямо сейчас, показывает ошибку если что-то не так |
| `/chatid` | Показать ID текущего чата (для настройки уведомлений) |
| `/set_notify <chat_id>` | Направить напоминания из этого чата в другой чат |
| `/unset_notify` | Отменить маршрутизацию напоминаний |
| `/notify_status` | Показать куда уходят напоминания из этого чата |
| `/webapp` | Открыть веб-интерфейс _(планируется)_ |

## Создание задачи

Бот принимает свободный текст. LLM извлекает задачу, затем бот предлагает подтверждение:

### Триггеры в групповом чате

| Формат | Описание |
|--------|----------|
| `@имя_бота <задача>` | Упоминание бота |
| `Бот <задача>` | Ключевое слово "Бот" в начале сообщения |
| `Бот @Маша <задача>` | Создать задачу с назначением на @Маша |

Если исполнитель не указан в тексте — после сохранения бот предложит выбрать из участников группы.

```
Пользователь: "Купить молоко завтра в 10"
      │
      ▼
LLM извлекает:
  title: "Купить молоко"
  time_expression: "завтра в 10"
      │
      ▼
Бот показывает карточку + клавиатуру подтверждения
```

### Клавиатура подтверждения

| Кнопка | Действие |
|--------|----------|
| ✅ Сохранить | Сохраняет задачу, ставит напоминание в планировщик |
| ❌ Пропустить | Отменяет, задача не создаётся |

**Если время не распознано:** устанавливается завтра 09:00 по местному времени.

**Если в тексте есть HH:MM** (но LLM не распознал): regex-фоллбек извлечёт время напрямую.

## Жизненный цикл задачи

```
                    ┌─────────────┐
                    │   PENDING   │◄──────────────┐
                    └──────┬──────┘               │
                           │ remind_at наступило   │
                           ▼                       │
                    ┌─────────────┐               │
                    │  Напоминание│               │
                    │  (бот шлёт) │               │
                    └──────┬──────┘               │
              ┌────────────┼────────────┐          │
              ▼            ▼            ▼          │
         [Отложить]  [В работу]    [Готово]        │
              │            │            │          │
              ▼            ▼            ▼          │
          PENDING       ACTIVE        DONE         │
         (новое         (через        (финал)      │
          время)       30 мин               │
                       check-in)            │
                           │                │
                    не выполнено            │
                           └────────────────┘
                            reset → PENDING
```

### Статусы задачи

| Статус | Описание |
|--------|----------|
| `pending` | Ожидает напоминания |
| `active` | Взята в работу, через 30 мин будет check-in |
| `done` | Выполнена |
| `cancelled` | Отменена |

## Клавиатура напоминания

Показывается когда приходит время задачи:

```
[ ⏱ Отложить ]  [ ▶️ Взять в работу ]  [ ✅ Готово ]
```

| Кнопка | callback | Действие |
|--------|----------|----------|
| ⏱ Отложить | `remind:snooze:{id}` | Заменяет кнопки на клавиатуру выбора времени |
| ▶️ Взять в работу | `remind:take:{id}` | Статус → `active`, через 30 мин check-in |
| ✅ Готово | `remind:done:{id}` | Статус → `done`, в группе добавляет @username |

> В групповом чате нажать может только назначенный исполнитель (`assignee_id`). Остальным: "Эта задача назначена другому участнику."

## Клавиатура откладывания (Snooze)

Появляется после нажатия "Отложить" или кнопки "⏱ Перенести" в `/list`:

```
[     +1 час     ]  [    +3 часа    ]
[ Вечером (19:00)]  [ Утром   (9:00)]
[         ✏️ Своё время             ]
```

| Кнопка | callback | Новое время |
|--------|----------|-------------|
| +1 час | `snooze:1h:{id}` | now + 1 час |
| +3 часа | `snooze:3h:{id}` | now + 3 часа |
| Вечером | `snooze:evening:{id}` | сегодня в `SNOOZE_EVENING_HOUR` (19:00), если прошло — завтра |
| Утром | `snooze:morning:{id}` | завтра в `SNOOZE_MORNING_HOUR` (9:00) |
| ✏️ Своё время | `snooze:custom:{id}` | FSM-режим: бот просит ввести время текстом |

### Ввод своего времени (FSM)

После нажатия "✏️ Своё время" бот ждёт текстовое сообщение:

```
Примеры:
  15:30          → сегодня в 15:30 (если прошло — завтра)
  завтра в 10    → завтра в 10:00
  через 2 часа   → now + 2 часа
  05.05 10:00    → 5 мая в 10:00
```

Парсинг через `dateparser` с настройкой `PREFER_DATES_FROM: future`.

## Клавиатура `/list`

Каждая задача отображается отдельным сообщением:

```
🔴 Название задачи
📅 18.04 12:50
заметка (если есть)

[ ✅ Готово ]  [ ⏱ Перенести ]
```

| Кнопка | callback | Действие |
|--------|----------|----------|
| ✅ Готово | `done_list:{id}` | Статус → `done` |
| ⏱ Перенести | `list_snooze:{id}` | Показывает snooze-клавиатуру |

Эмодзи приоритета: 🔴 high · 🟡 medium · 🔵 low

Если задача имеет исполнителя — отображается строка `👤 @username`.

## Две группы: задачи + напоминания

Позволяет разделить **шумный чат задач** (создание, списки, обсуждения) и **тихий чат напоминаний** (только уведомления с кнопками).

### Зачем

- В чате задач много сообщений: команды `/add`, `/list`, подтверждения, обсуждения
- В чате напоминаний — только напоминалки, важное не теряется в шуме

### Пошаговая настройка

1. **Создай в Telegram две группы**, например «Семья: задачи» и «Семья: напоминания»
2. **Добавь Muninn в обе группы**
3. **В группе напоминаний** напиши `/chatid` — бот покажет ID (например `-1001234567890`)
4. **В группе задач** напиши `/set_notify -1001234567890` — бот проверит что он есть в целевой группе и сохранит маршрутизацию
5. **Проверь:** `/notify_status` → покажет куда уходят напоминания
6. **Тест:** `/add Проверка через минуту` → напоминание должно прийти в группу напоминаний, а не задач

### Что работает автоматически

- Все **напоминания задач** из чата задач → летят в чат напоминаний
- **Алерты Google Doc** (когда приближаются даты из отслеживаемых документов) → тоже роутятся через настройку
- **Кнопки управления** (Отложить / Беру / Готово) работают там, где пришло уведомление
- **Follow-up check** после "В работу" → приходит в тот же чат напоминаний

### Что остаётся в чате задач

- Команды `/add`, `/list`, `/today`, `/done`, `/sync`, `/watch`, `/sources`, `/family`
- Карточки подтверждения при создании задачи
- Ответы бота на текстовые сообщения
- Отчёты по `/watch` проверкам

### Отмена маршрутизации

В чате задач выполни `/unset_notify` — напоминания снова будут приходить туда же где создаются задачи.

### Личный чат

В личке с ботом всё работает как раньше: задачи создаются и напоминания приходят в тот же личный чат. Если хочешь направить личные напоминания в отдельный чат (например канал-дайджест) — `/set_notify <id>` в личке тоже работает.

### Диаграмма

```
[Семья: задачи 💬]        [Личный чат 🔒]
  /add Купить молоко         /add Витамин D
         │                          │
         └──────── Muninn ──────────┘
                      │
         ┌────────────┴──────────────┐
         ↓                           ↓
[Семья: напоминания 🔔]      [Личный чат 🔒]
  "🔔 Купить молоко"           "🔔 Витамин D"
  [Отложить] [Беру!] [✅]      [Отложить] [✅]
```

## Клавиатура эскалации

Появляется когда задача откладывалась `ESCALATION_SNOOZE_COUNT` раз подряд (по умолчанию 3):

```
[ ⬆️ Повысить приоритет ]  [ 👤 Переназначить ]  [ Оставить как есть ]
```

| Кнопка | callback | Действие |
|--------|----------|----------|
| ⬆️ Повысить приоритет | `escalate:priority:{id}` | Priority → `high`, снова показывает reminder_keyboard |
| 👤 Переназначить | `escalate:reassign:{id}` | Подсказка по ручному переназначению _(UI не реализован)_ |
| Оставить как есть | `escalate:ignore:{id}` | Закрывает эскалацию, возвращает reminder_keyboard |

## Обнаружение выполнения по тексту

Бот ищет ключевые слова в сообщениях:

```
выполнил / выполнила / сделал / сделала / готово / закончил /
закончила / завершил / завершила / done / finished / completed
```

Если найдено — показывает список задач с кнопкой "✅ Готово" для каждой.

## Синхронизация с Google Tasks

Команда `/sync` запускает двустороннюю синхронизацию:

```
Google → Бот:
  • Новые задачи из Google → создаются в боте
  • Время: из заметки "⏰ HH:MM" (если есть), иначе 09:00 на дату дедлайна
  • Если дата не указана → завтра в 09:00
  • Задачи без времени → бот спросит время через snooze-клавиатуру

Бот → Google:
  • Новые задачи бота → создаются в Google (первый список)
  • Время пишется в заметку: "⏰ 14:00"
  • Обновляются если бот изменился позже последней синхронизации
```

## Модель данных

```
Task
├── id: UUID
├── title: str
├── notes: str?
├── status: pending | active | done | cancelled
├── priority: low | medium | high
├── source: manual | google_tasks | google_doc | md_file
├── remind_at: datetime (UTC)
├── due_at: datetime? (UTC)
├── snoozed_until: datetime?
├── snooze_count: int
├── recurrence: cron string?
├── owner_id: telegram_id
├── chat_id: telegram_chat_id
├── assignee_id: telegram_id?
├── assignee_username: str?          # @username исполнителя
├── notify_chat_id: telegram_chat_id? # куда отправлять напоминания
├── is_family: bool
├── google_task_id: str?
├── google_tasklist_id: str?
└── google_updated_at: datetime?

WatchedSource
├── id: UUID
├── url: str
├── source_type: google_doc | md_file
├── owner_id: telegram_id
├── chat_id: telegram_chat_id
├── reminder_lead_days: int (default 3)
└── last_checked: datetime?

User
├── telegram_id: int
├── username: str?
└── family_chat_id: int?

ChatSettings
├── chat_id: telegram_chat_id
└── notify_chat_id: telegram_chat_id?

ChatMember          # участники групп (запоминаются автоматически)
├── chat_id: telegram_chat_id
├── user_id: telegram_id
├── username: str?
└── first_name: str
```

## Конфигурация (.env)

| Переменная | Описание | Пример |
|------------|----------|--------|
| `BOT_TOKEN` | Telegram Bot API token | `123:ABC...` |
| `LLM_PROVIDER` | Провайдер LLM | `groq` / `anthropic` / `ollama` |
| `LLM_API_KEY` | API ключ провайдера | `gsk_...` |
| `LLM_MODEL` | Модель (пусто = дефолт провайдера) | `llama-3.3-70b-versatile` |
| `DATABASE_PATH` | Путь к SQLite файлу | `data/bot.db` |
| `TIMEZONE` | Локальный часовой пояс | `Asia/Vladivostok` |
| `SNOOZE_EVENING_HOUR` | Час для "Вечером" | `19` |
| `SNOOZE_MORNING_HOUR` | Час для "Утром" | `9` |
| `ESCALATION_SNOOZE_COUNT` | Кол-во откладываний до эскалации | `3` |
| `GDRIVE_SERVICE_ACCOUNT_JSON` | Путь к service account JSON | `credentials/service_account.json` |
| `GDRIVE_BACKUP_FOLDER_ID` | ID папки Google Drive для бэкапа (не используется) | `1XNA5...` |
| `BACKUP_CHAT_ID` | Telegram chat ID куда слать бэкапы (пусто = чат откуда вызван /backup) | `-1001234567890` |
| `GOOGLE_TASKS_TOKEN_PATH` | Путь к OAuth токену Google Tasks | `credentials/google_tasks_token.json` |
