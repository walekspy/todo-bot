# Справочник по боту

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | Регистрация пользователя, приветствие |
| `/list` | Список всех активных задач с кнопками управления |
| `/today` | Задачи, запланированные на сегодня |
| `/done` | Показать список задач для отметки выполненными |
| `/add` | Режим добавления задачи: бот просит написать задачу и время, затем показывает карточку подтверждения |
| `/sync` | Синхронизация с Google Tasks (двусторонняя) |
| `/watch <url>` | Начать следить за Google Doc, ежедневная проверка в 06:00 |
| `/sources` | Список отслеживаемых документов |
| `/family` | Список семейных задач с исполнителями |
| `/webapp` | Открыть веб-интерфейс _(планируется)_ |

## Создание задачи

Бот принимает свободный текст. LLM извлекает задачу, затем бот предлагает подтверждение:

```
Пользователь: "Купить молоко завтра в 10"
      │
      ▼
LLM извлекает:
  title: "Купить молоко"
  time_expression: "завтра в 10"
      │
      ▼
Бот показывает карточку + клавиатуру подтверждения
```

### Клавиатура подтверждения

| Кнопка | Действие |
|--------|----------|
| ✅ Сохранить | Сохраняет задачу, ставит напоминание в планировщик |
| ❌ Пропустить | Отменяет, задача не создаётся |

**Если время не распознано:** устанавливается завтра 09:00 по местному времени.

**Если в тексте есть HH:MM** (но LLM не распознал): regex-фоллбек извлечёт время напрямую.

## Жизненный цикл задачи

```
                    ┌─────────────┐
                    │   PENDING   │◄──────────────┐
                    └──────┬──────┘               │
                           │ remind_at наступило   │
                           ▼                       │
                    ┌─────────────┐               │
                    │  Напоминание│               │
                    │  (бот шлёт) │               │
                    └──────┬──────┘               │
              ┌────────────┼────────────┐          │
              ▼            ▼            ▼          │
         [Отложить]  [В работу]    [Готово]        │
              │            │            │          │
              ▼            ▼            ▼          │
          PENDING       ACTIVE        DONE         │
         (новое         (через        (финал)      │
          время)       30 мин               │
                       check-in)            │
                           │                │
                    не выполнено            │
                           └────────────────┘
                            reset → PENDING
```

### Статусы задачи

| Статус | Описание |
|--------|----------|
| `pending` | Ожидает напоминания |
| `active` | Взята в работу, через 30 мин будет check-in |
| `done` | Выполнена |
| `cancelled` | Отменена |

## Клавиатура напоминания

Показывается когда приходит время задачи:

```
[ ⏱ Отложить ]  [ ▶️ Взять в работу ]  [ ✅ Готово ]
```

| Кнопка | callback | Действие |
|--------|----------|----------|
| ⏱ Отложить | `remind:snooze:{id}` | Заменяет кнопки на клавиатуру выбора времени |
| ▶️ Взять в работу | `remind:take:{id}` | Статус → `active`, через 30 мин check-in |
| ✅ Готово | `remind:done:{id}` | Статус → `done`, в группе добавляет @username |

> В групповом чате нажать может только назначенный исполнитель (`assignee_id`). Остальным: "Эта задача назначена другому участнику."

## Клавиатура откладывания (Snooze)

Появляется после нажатия "Отложить" или кнопки "⏱ Перенести" в `/list`:

```
[     +1 час     ]  [    +3 часа    ]
[ Вечером (19:00)]  [ Утром   (9:00)]
[         ✏️ Своё время             ]
```

| Кнопка | callback | Новое время |
|--------|----------|-------------|
| +1 час | `snooze:1h:{id}` | now + 1 час |
| +3 часа | `snooze:3h:{id}` | now + 3 часа |
| Вечером | `snooze:evening:{id}` | сегодня в `SNOOZE_EVENING_HOUR` (19:00), если прошло — завтра |
| Утром | `snooze:morning:{id}` | завтра в `SNOOZE_MORNING_HOUR` (9:00) |
| ✏️ Своё время | `snooze:custom:{id}` | FSM-режим: бот просит ввести время текстом |

### Ввод своего времени (FSM)

После нажатия "✏️ Своё время" бот ждёт текстовое сообщение:

```
Примеры:
  15:30          → сегодня в 15:30 (если прошло — завтра)
  завтра в 10    → завтра в 10:00
  через 2 часа   → now + 2 часа
  05.05 10:00    → 5 мая в 10:00
```

Парсинг через `dateparser` с настройкой `PREFER_DATES_FROM: future`.

## Клавиатура `/list`

Каждая задача отображается отдельным сообщением:

```
🔴 Название задачи
📅 18.04 12:50
заметка (если есть)

[ ✅ Готово ]  [ ⏱ Перенести ]
```

| Кнопка | callback | Действие |
|--------|----------|----------|
| ✅ Готово | `done_list:{id}` | Статус → `done` |
| ⏱ Перенести | `list_snooze:{id}` | Показывает snooze-клавиатуру |

Эмодзи приоритета: 🔴 high · 🟡 medium · 🔵 low

---

## Клавиатура эскалации

Появляется когда задача откладывалась `ESCALATION_SNOOZE_COUNT` раз подряд (по умолчанию 3):

```
[ ⬆️ Повысить приоритет ]  [ 👤 Переназначить ]  [ Оставить как есть ]
```

| Кнопка | callback | Действие |
|--------|----------|----------|
| ⬆️ Повысить приоритет | `escalate:priority:{id}` | Priority → `high`, снова показывает reminder_keyboard |
| 👤 Переназначить | `escalate:reassign:{id}` | Подсказка по ручному переназначению _(UI не реализован)_ |
| Оставить как есть | `escalate:ignore:{id}` | Закрывает эскалацию, возвращает reminder_keyboard |

## Обнаружение выполнения по тексту

Бот ищет ключевые слова в сообщениях:

```
выполнил / выполнила / сделал / сделала / готово / закончил /
закончила / завершил / завершила / done / finished / completed
```

Если найдено — показывает список задач с кнопкой "✅ Готово" для каждой.

## Планировщик (APScheduler)

| Задание | Триггер | Описание |
|---------|---------|----------|
| `task_reminder_job` | `date` (одноразово) | Отправляет напоминание в нужное время |
| `checkin_job` | `date` +30 мин | Проверка после "Взять в работу" |
| `doc_check_job` | `cron` 06:00 UTC | Проверка Google Doc на предстоящие события |
| `backup_job` | `cron` 03:00 UTC | Бэкап БД на Google Drive |

## Синхронизация с Google Tasks

Команда `/sync` запускает двустороннюю синхронизацию:

```
Google → Бот:
  • Новые задачи из Google → создаются в боте
  • Время: из заметки "⏰ HH:MM" (если есть), иначе 09:00 на дату дедлайна
  • Если дата не указана → завтра в 09:00
  • Задачи без времени → бот спросит время через snooze-клавиатуру

Бот → Google:
  • Новые задачи бота → создаются в Google (первый список)
  • Время пишется в заметку: "⏰ 14:00"
  • Обновляются если бот изменился позже последней синхронизации
```

## Модель данных

```
Task
├── id: UUID
├── title: str
├── notes: str?
├── status: pending | active | done | cancelled
├── priority: low | medium | high
├── source: manual | google_tasks | google_doc | md_file
├── remind_at: datetime (UTC)
├── due_at: datetime? (UTC)
├── snoozed_until: datetime?
├── snooze_count: int
├── recurrence: cron string?
├── owner_id: telegram_id
├── chat_id: telegram_chat_id
├── assignee_id: telegram_id?
├── is_family: bool
├── google_task_id: str?
├── google_tasklist_id: str?
└── google_updated_at: datetime?

WatchedSource
├── id: UUID
├── url: str
├── source_type: google_doc | md_file
├── owner_id: telegram_id
├── chat_id: telegram_chat_id
├── reminder_lead_days: int (default 3)
└── last_checked: datetime?

User
├── telegram_id: int
├── username: str?
└── family_chat_id: int?
```
