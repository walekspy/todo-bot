# Telegram Reminder Bot — Design Spec

**Date:** 2026-04-15  
**Status:** Draft

---

## Overview

Telegram-бот для управления задачами и напоминаниями. Задачи попадают из разных источников (ручной ввод, Google Docs, медицинские документы и др.). Поддерживает личный режим и семейные группы. Архитектура — чистый монолит с внутренними слоями, расширяемый для новых источников.

---

## Architecture

Единый Python-процесс с чёткими внутренними слоями:

```
Sources (adapters)
    ↓
LLM Extractor (Claude API)
    ↓
Confirmation UI (Telegram)
    ↓
Task Repository (SQLite)
    ↓ ↑
Scheduler (APScheduler, persistent)
    ↓
Bot UI Layer (aiogram v3)
    ↓
Telegram (личные чаты + группы)
```

**Стек:**
- Python 3.12+
- aiogram v3 — Telegram bot framework
- APScheduler с SQLite job store — планировщик, переживает рестарт
- SQLite — хранилище задач и событий
- Claude API (Anthropic) — извлечение задач из текста и определение сроков напоминаний
- google-api-python-client — чтение публичных Google Docs

**Принцип расширяемости:** каждый источник задач — отдельный адаптер, реализующий интерфейс `SourceAdapter`. Новый источник добавляется как новый модуль без изменения остального кода.

## Task Model

Единая модель для всех задач независимо от источника:

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | UUID | Уникальный идентификатор |
| `title` | str | Текст задачи |
| `notes` | str? | Доп. описание или контекст |
| `status` | enum | `pending` / `active` / `done` / `cancelled` |
| `priority` | enum | `low` / `medium` / `high` |
| `source` | str | `manual` / `google_doc` / `md_file` / … |
| `source_ref` | str? | Ссылка на источник (URL, имя файла) |
| `due_at` | datetime? | Срок выполнения |
| `remind_at` | datetime | Когда отправить напоминание |
| `recurrence` | str? | Cron-выражение для повторяющихся задач |
| `snoozed_until` | datetime? | До когда отложена |
| `snooze_count` | int | Сколько раз откладывалась |
| `owner_id` | int | Telegram user ID создателя |
| `assignee_id` | int? | Кому назначена (может отличаться от owner) |
| `chat_id` | int | ID чата (личный или группа) |
| `is_family` | bool | Видна ли всей группе |
| `created_at` | datetime | Дата создания |

**Правило эскалации:** после 3-го откладывания бот предлагает повысить приоритет или переназначить задачу другому члену семьи.

## Notification Types

Система различает два типа уведомлений:

### 1. Напоминание о задаче
Приходит по `remind_at`. Кнопки:
- **⏱ Отложить** → умные варианты: +1ч / +3ч / Вечером (19:00) / Завтра утром (09:00) / Другое время
- **▶️ Взять в работу** → статус `active`, через 30 минут фиксированный контрольный вопрос "выполнена?" (не настраивается в v1)
- **✅ Готово** → статус `done`; для повторяющихся задач создаётся следующее вхождение

### 2. Событие из наблюдаемого документа
Бот сам проверяет зарегистрированные Google Docs по расписанию. При приближении даты отправляет уведомление:

> "Через 3 дня: **оплата кредита**. Создать задачу?"

Кнопки: **[✅ Создать задачу]** / **[❌ Пропустить]**

При создании задачи — стандартный флоу подтверждения перед сохранением.

## Source Adapters

Все адаптеры реализуют интерфейс:

```python
class SourceAdapter:
    async def extract(self, input: str) -> list[RawTask]:
        """Принимает сырые данные, возвращает список неподтверждённых задач."""
```

### Адаптеры v1:

**ManualAdapter** — свободный текст от пользователя. LLM парсит намерение и вычленяет задачу с датой и приоритетом. Работает и с командой `/add`, и без команды.

**GoogleDocAdapter** — URL публичного Google Doc. При регистрации через `/watch` LLM анализирует документ и определяет тип (список дат, задачи, расписание) и предлагаемый срок предупреждения для каждого события. Периодическая проверка — раз в сутки. При изменении документа — повторный анализ дельты.

**MdFileAdapter** — пользователь отправляет MD-файл напрямую в чат бота. LLM извлекает назначения (витамины, прививки, обследования) и предлагает задачи с периодичностью.

### Флоу подтверждения (все адаптеры):

Для каждой извлечённой задачи бот отправляет превью:
```
📋 Предлагаемая задача:
Витамин D — 2 капли
📅 Ежедневно | ⚡ Приоритет: средний

[✅ Сохранить] [✏️ Изменить] [❌ Пропустить]
```
Задача попадает в БД только после явного подтверждения.

## Family Group Support

- Бот добавляется в семейный Telegram-чат
- Задача помечается `is_family=True` и привязывается к `chat_id` группы
- Все участники группы видят сообщения со статусами задач
- **Кнопки управления видит только `assignee`** — остальные видят только статус
- При нажатии "Готово" сообщение обновляется: `✅ Выполнено @username`
- Кнопка **👤 Передать** позволяет переназначить задачу другому участнику группы

## Bot Commands

| Команда | Описание |
|---------|----------|
| `/add` | Добавить задачу вручную |
| `/list` | Список активных задач |
| `/today` | Задачи на сегодня |
| `/watch <url>` | Зарегистрировать Google Doc для слежения |
| `/sources` | Список наблюдаемых документов |
| `/done` | Отметить задачу выполненной |
| `/family` | Семейные задачи группы |

**Свободный текст** без команды → ManualAdapter → LLM → флоу подтверждения.

## Scheduler

APScheduler с `SQLAlchemyJobStore` на SQLite — задания сохраняются между рестартами.

Типы заданий:
- **task_reminder** — разовое или повторяющееся, по `remind_at` / `recurrence`
- **doc_check** — ежесуточная проверка каждого наблюдаемого документа
- **backup** — ежесуточный бэкап БД в Google Drive

---

## Backup

Ежесуточно (ночью) SQLite-файл копируется в Google Drive в папку `RemindBot/backups/`. Используется Google Drive API с сервисным аккаунтом (не требует OAuth от пользователя). Хранится 30 последних бэкапов, старые удаляются автоматически.

---

## Storage

Одна SQLite база, три основных таблицы:

- `tasks` — все задачи (модель выше)
- `watched_sources` — зарегистрированные Google Docs и MD-файлы (url, last_checked, check_interval, reminder_lead_days)
- `users` — Telegram user ID, имя, привязка к семейной группе

APScheduler использует отдельную таблицу `apscheduler_jobs` в той же БД.

---

## Out of Scope (v1)

- Голосовой ввод (запланировано на v2)
- Web-интерфейс / дашборд
- Push-уведомления вне Telegram
- Несколько семейных групп на один аккаунт
- Интеграция с календарями (Google Calendar, Apple Calendar)
